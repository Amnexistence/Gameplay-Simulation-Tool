Справка GameFlow

Философия

Всё состоит из сущностей с параметрами. Любое игровое событие — это изменение параметров одной или нескольких сущностей. «Передача ресурса» = два изменения параметров в одном событии (у одной сущности −, у другой +).

Карта сущностей

Точки — сущности, стрелки — воздействия на параметры других сущностей. Цвет стрелки = цвет события, которое её создаёт. Наведите курсор на стрелку, чтобы увидеть подробности. Клик по сущности открывает панель настроек.

Дерево событий

У каждой сущности своё дерево событий (вкладка «События»). Событие длится заданное время, затем применяет свои воздействия и выбирает переход. Переходы выбираются по приоритету (больше — раньше проверяется), условию и шансу. Если подходящий переход не найден и включён автоцикл, процесс возвращается в точку входа. Событие может повторяться с заданным шансом/условием/лимитом.

Формулы и условия

Значение воздействия и условие — число или формула. Доступно: + − * / % ^, скобки, сравнения == != < > <= >=, логика && || !, тернарный ? :, функции min max abs round floor ceil sqrt pow log exp sin cos rand(a,b).

Переменные: имя_параметра — параметр текущей сущности, Имя_сущности.имя_параметра — любой глобальный параметр. Пример: -(5 + агрессия * 0.5), Королевство.золото < 100.

Панель воздействий (🔍)

Клик по 🔍 у параметра показывает все события всех сущностей, которые его меняют. Карта подсвечивает только источники. Там же задаётся приоритет: при одновременном изменении параметра несколькими источниками первым применяется воздействие с большим приоритетом.

Данные

Всё сохраняется в localStorage автоматически. Импорт/экспорт — JSON-файл со всеми страницами. Пробел — старт/пауза симуляции.
