Журнал симуляции
Справка GameFlow

Философия

Всё состоит из сущностей с параметрами. Любое игровое событие — это изменение параметров одной или нескольких сущностей. «Передача ресурса» = два изменения параметров в одном событии (у одной сущности −, у другой +).

Карта сущностей

Точки — сущности, стрелки — воздействия на параметры других сущностей. Цвет стрелки = цвет события, которое её создаёт. Наведите курсор на стрелку, чтобы увидеть подробности. Клик по сущности открывает панель настроек.

Дерево событий

У каждой сущности своё дерево событий (вкладка «События»). Событие длится заданное время, затем применяет свои воздействия и выбирает переход. Переходы выбираются по приоритету (больше — раньше проверяется), условию и шансу. Если подходящий переход не найден и включён автоцикл, процесс возвращается в точку входа. Событие может повторяться с заданным шансом/условием/лимитом.

Формулы и условия

Значение воздействия и условие — число или формула. Доступно: + − * / % ^, скобки, сравнения == != < > <= >=, логика && || !, тернарный ? :, функции min max abs round floor ceil sqrt pow log exp sin cos rand(a,b).

Переменные: имя_параметра — параметр текущей сущности, Имя_сущности.имя_параметра — любой глобальный параметр. Имена с пробелами и разделителями — в кавычках: "в войне", Враг."в войне". При вводе формулы появляется список автоподстановки имён.

Примеры: -(5 + агрессия * 0.5), Королевство.золото < 100.

Шансы

Шанс воздействия, перехода и повтора — число в процентах (75) или формула, результат которой тоже в процентах (например агрессия * 10).

Типы параметров

Параметры бывают число (с опциональными мин/макс: значение зажимается в границы, но воздействие не блокируется), текст и булев. Операции несовместимых типов невозможны: к числу += = ×=, к булеву = (по формуле) и инверсия, к тексту только =. В формулах булев даёт 1/0, текст как число использовать нельзя.

Повторы и приоритеты

Повтор события — по сути переход сам в себя: он конкурирует с обычными переходами по приоритету (поле «Приоритет» в блоке повтора). Приоритет воздействия решает, какое из одновременных изменений параметра применится первым.

Отладка

⏭ Шаг — продвинуть симуляцию на указанное число секунд (на паузе). Поле «⏹ стоп-условие» в тулбаре — формула: когда она становится истинной, симуляция останавливается автоматически (напр. Королевство.золото <= 0).

Страницы

Кнопка 📄 в тулбаре открывает менеджер страниц: полные названия, открытие кликом, переименование (✎), массовое удаление отмеченных галочками, снятие пометок «(дубль N)». Импорт JSON добавляет страницы к текущим, совпавшие имена получают пометку дубля.

Стрелки на карте

Одна стрелка на пару «событие → целевая сущность»: толщина растёт с числом меняемых параметров, рядом подпись (параметры с операциями += = ×= inv и длительность события ⏱). Тултип стрелки перечисляет все изменения столбиком. Стрелки активного события подсвечиваются бегущим пунктиром.

Панель воздействий (🔍)

Клик по 🔍 у параметра показывает все события всех сущностей, которые его меняют. Карта подсвечивает только источники. Там же задаётся приоритет: при одновременном изменении параметра несколькими источниками первым применяется воздействие с большим приоритетом.

Данные

Всё сохраняется в localStorage автоматически. Импорт/экспорт — JSON-файл со всеми страницами. Пробел — старт/пауза симуляции.
