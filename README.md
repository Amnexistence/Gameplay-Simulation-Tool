# GameFlow — интерактивный симулятор игровых процессов

SPA без бэкенда (только HTML/CSS/JS). Философия: всё состоит из **изменений параметров сущностей в событиях** (в отличие от ресурсных диаграмм Machinations). «Передача ресурса» = два изменения параметров двух сущностей в одном событии.

## Запуск

Просто откройте `index.html` в браузере (бэкенд не нужен). Все данные сохраняются в localStorage автоматически.

## Основные понятия

- **Страница** — отдельная схема (вкладки в тулбаре; можно добавлять/удалять/очищать, импортировать/экспортировать в JSON).
- **Сущность** — точка на карте с набором параметров (стартовые значения настраиваются). Клик по точке открывает панель сущности.
- **Дерево событий** — у каждой сущности своё: ноды-события, соединённые переходами (последовательно или с ветвлениями).
- **Событие** — длится заданное время, затем применяет **воздействия** (изменения параметров любых сущностей) и выбирает переход.
- **Воздействие** — цель (сущность + параметр), операция (`+=`, `=`, `×=`), величина (число или формула), условие, шанс, приоритет.
- **Переход** — условие, шанс, приоритет (при ветвлении переходы проверяются по убыванию приоритета).
- **Повтор события** — шанс + условие + лимит повторов.
- **Автоцикл** — если подходящего перехода нет, процесс возвращается в точку входа (настраивается).
- **Панель воздействий (🔍 у параметра)** — список всех нод всех сущностей, меняющих параметр; приоритеты при одновременном изменении; карта затемняет всё лишнее и подсвечивает источники.

## Стрелки на карте

Цвет стрелки = цвет события-источника. Наведение на стрелку показывает: сущность ▸ событие → цель.параметр: изменение [условие] [шанс]. Петля над сущностью — воздействие на саму себя.

## Формулы и условия

- Операторы: `+ - * / % ^`, скобки; сравнения `== != < > <= >=`; логика `&& || !`; тернарный `? :`.
- Функции: `min max abs round floor ceil sqrt pow log exp sin cos rand(a,b)`.
- Переменные: `имя_параметра` — параметр текущей сущности; `Сущность.имя_параметра` — глобально (все параметры всех сущностей глобальны).
- Примеры: `10 + население * 0.1`, `-(5 + агрессия * 0.5)`, условие `Королевство.армия < армия`.

## Симуляция

- ▶ Старт / ⏸ Пауза (или Пробел), ⟲ Сброс (возврат параметров к стартовым).
- Скорость ×0.25 … ×16. Активные события подсвечиваются на карте и в дереве, изменения «всплывают» над сущностями, всё пишется в журнал.
- Одновременные изменения одного параметра применяются по приоритету (больший — раньше).

## Управление картой

- Клик по сущности — панель; перетаскивание — перемещение; двойной клик по фону — новая сущность.
- Колесо мыши — масштаб, перетаскивание фона — панорама, «⤢ Вписать» — показать всё.

## Дерево событий

- Двойной клик по полю — новое событие; перетаскивание ноды — перемещение.
- Тяните от жёлтого порта (справа на ноде) к другой ноде — создастся переход; ✕ на середине ребра — удалить.
- Клик по ноде — инспектор: цвет, длительность, повторы, воздействия, переходы, точка входа.

## Данные

- Автосохранение в localStorage (значения симуляции не сохраняются — только схема).
- «⇩ Экспорт» — все страницы в `gameflow-scheme.json`; «⇧ Импорт» — загрузка файла (текущие страницы заменяются).

## Структура

```
index.html          разметка SPA
css/style.css       стили (тёмная тема)
js/formula.js       парсер/вычислитель формул (без eval)
js/store.js         модель данных, localStorage, нормализация, импорт/экспорт, демо-схема
js/engine.js        движок симуляции (процессы, условия, шансы, приоритеты)
js/mapview.js       карта сущностей (SVG: стрелки, подсветки, pan/zoom)
js/panel.js         панель сущности, редактор дерева, инспектор, панель воздействий
js/app.js           тулбар, страницы, журнал, связывание всего вместе
```
