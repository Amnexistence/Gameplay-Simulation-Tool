# GameFlow — интерактивный симулятор игровых процессов

SPA без бэкенда (только HTML/CSS/JS). Философия: всё состоит из **изменений параметров сущностей в событиях** (в отличие от ресурсных диаграмм Machinations). «Передача ресурса» = два изменения параметров двух сущностей в одном событии.

## Запуск

Просто откройте `index.html` в браузере (бэкенд не нужен). Все данные сохраняются в localStorage автоматически.

## Основные понятия

- **Страница** — отдельная схема. Кнопка **📄** в тулбаре открывает менеджер страниц: полные названия, открытие кликом, переименование (✎), массовое удаление отмеченных галочками, снятие пометок «(дубль N)».
- **Сущность** — точка на карте с набором параметров. Клик по точке открывает панель сущности.
- **Параметр** — имя, **тип** (число / текст / булев), стартовое значение, для чисел — **мин/макс** (значение зажимается в границы, но воздействие не блокируется: 3 − 4 при минимуме 0 даст 0). Операции несовместимых типов невозможны: число `+= = ×=`, булев `= (по формуле)` и `инверсия`, текст только `= (текст)`. В формулах булев даёт 1/0, текст как число использовать нельзя.
- **Дерево событий** — у каждой сущности своё, на **бесконечном полотне** (прокрутка в любые стороны): ноды-события, соединённые переходами.
- **Событие** — длится заданное время, затем применяет **воздействия** и выбирает следующий шаг.
- **Воздействие** — цель (сущность + параметр), операция, величина (число или формула), условие, шанс, приоритет.
- **Переход** — условие, шанс, приоритет (при ветвлении проверяются по убыванию приоритета).
- **Повтор события** — шанс + условие + лимит + **приоритет**: повтор конкурирует с переходами в другие события как «переход сам в себя».
- **Автоцикл** — если ни повтор, ни переходы не подошли, процесс возвращается в точку входа (настраивается).
- **Панель воздействий (🔍 у параметра)** — все ноды всех сущностей, меняющие параметр; приоритеты при одновременном изменении; карта затемняет всё лишнее и подсвечивает источники.

## Формулы, имена с пробелами, автоподстановка

- Операторы: `+ - * / % ^`, скобки; сравнения `== != < > <= >=`; логика `&& || !`; тернарный `? :`.
- Функции: `min max abs round floor ceil sqrt pow log exp sin cos rand(a,b)`.
- Переменные: `имя_параметра` (текущая сущность), `Сущность.имя_параметра` (глобально). Имена с пробелами и разделителями — **в кавычках**: `"в войне"`, `Враг."в войне"`.
- При вводе любой формулы/условия появляется **выпадающий список автоподстановки** имён (сущности, `сущность.параметр`, свои параметры); имена с пробелами вставляются уже в кавычках.
- Примеры: `10 + население * 0.1`, `-(5 + агрессия * 0.5)`, `Королевство.армия < армия && Враг."в войне" == 0`.

## Шансы

Шанс воздействия, перехода и повтора — **число в процентах** (`75`) или **формула**, результат которой тоже в процентах (например `агрессия * 10`). Поля шансов принимают оба варианта и подсвечивают ошибки.

## Симуляция и отладка

- ▶ Старт / ⏸ Пауза (или Пробел), ⟲ Сброс (возврат параметров к стартовым).
- Скорость ×0.25 … ×16.
- **⏭ Шаг** — пошаговый дебаг: продвинуть симуляцию на указанное число секунд (работает на паузе).
- **⏹ стоп-условие** (поле в тулбаре) — формула: когда она становится истинной, симуляция останавливается автоматически (напр. `Королевство.золото <= 0`).
- Активные события подсвечиваются на карте (кольцо вокруг сущности) и в дереве; **стрелки активного события** анимируются бегущим пунктиром.
- Одновременные изменения одного параметра применяются по приоритету (больший — раньше).
- Журнал внизу фиксирует все применения, повторы, ошибки формул и системные события; высоту журнала можно менять перетаскиванием.

## Карта сущностей

- Одна стрелка на пару «событие → целевая сущность»: **толщина растёт** с числом меняемых параметров (в разумных пределах).
- Рядом со стрелкой подпись: меняемые параметры с операциями (`+=`, `=`, `×=`, `inv`) и **длительность события** (⏱).
- Тултип стрелки перечисляет все изменения **столбиком** (воздействие + пустая строка между ними), с условиями и шансами.
- Цвет стрелки = цвет события-источника; петля над сущностью — воздействие на саму себя.
- Клик по сущности — панель; перетаскивание — перемещение; двойной клик по фону — новая сущность; колесо — масштаб; фон — панорама; «⤢ Вписать» — показать всё.
- Ширину правой панели и высоту журнала можно менять перетаскиванием границ (сплиттеры); размеры запоминаются.

## Дерево событий

- Полотно 4000×4000 с прокруткой в любые стороны (события можно добавлять бесконечно во всех направлениях); при открытии центрируется на точке входа.
- Двойной клик по полю — новое событие в этом месте; перетаскивание ноды — перемещение.
- Тяните от порта (◆ справа на ноде) к другой ноде — создастся переход; ✕ на середине ребра — удалить.
- Клик по ноде — инспектор: цвет, длительность, повторы (шанс-формула, условие, лимит, приоритет), воздействия, переходы, точка входа.
- Позиции прокрутки сохраняются: добавление воздействий/событий не сбрасывает скролл, вкладки помнят свои позиции.

## Данные

- Автосохранение в localStorage (значения симуляции не сохраняются — только схема и настройки интерфейса).
- «⇩ Экспорт» — все страницы в `gameflow-scheme.json`.
- «⇧ Импорт» — **добавляет** страницы файла к текущим без затирания; совпавшие названия получают пометку «(дубль N)»; пометки можно массово снять в менеджере страниц, когда базовое имя свободно. Файлы старого формата (шансы числами 0..1, параметры без типов) мигрируют автоматически.

## Структура

```
index.html          разметка SPA
css/style.css       стили (тёмная тема)
js/formula.js       парсер/вычислитель формул (без eval), имена в кавычках
js/store.js         модель данных, типы параметров, localStorage, миграции, импорт/экспорт, демо
js/engine.js        движок: процессы, условия, шансы-формулы, приоритеты (воздействий и повторов),
                    min/max, типы, стоп-условие, пошаговый шаг
js/mapview.js       карта: группировка стрелок, толщина/подписи/тултипы, подсветка активности, pan/zoom
js/panel.js         панель сущности, бесконечное дерево, инспектор, панель воздействий, скролл-память
js/autocomplete.js  автоподстановка имён сущностей/параметров в формулы
js/app.js           тулбар, менеджер страниц, сплиттеры, журнал, связывание всего вместе
```
